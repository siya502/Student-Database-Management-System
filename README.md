# Student-Database-Management-System
Student Database Management System | MySQL | Stored Procedures | Joins | Aggregate Functions
## Overview
A mini project developed using MySQL to manage student records, subjects, and marks.
## Features
- Store student details
- Add subjects
- Record marks
- Generate student performance reports
- Calculate total and average marks
## Database Tables
1. Students
2. Subjects
3. Marks
## Technologies Used
- MySQL
- SQL Procedures
- Joins
- Aggregate Functions

## SQL Concepts Used
- Database Creation
- Tables
- Primary Keys
- Foreign Keys
- Stored Procedures
- Joins
- Group By
- Aggregate Functions

## Sample Output

Displays:
- Student Name
- Subject Name
- Marks
- Total Marks
- Average Marks
